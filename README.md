# Dragon-Repeller-Text-RPG-
**Dragon Repeller** is a simple text-based RPG game built using HTML, CSS, and JavaScript. Your goal is to defeat the mighty dragon terrorizing the town!

## Features

- Interactive game with buttons for navigation and combat
- Gold and health system
- Weapon upgrades and inventory management
- Multiple enemy types with different difficulty levels
- Secret mini-game (Easter Egg)
- Win/Lose mechanics with replay options
